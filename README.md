# MSJawad.github.io

The personal website of Solaiman Jawad, software engineer: work history, projects, education, contact details and resume on a single page.

Live at https://msjawad.github.io.

It is plain HTML and CSS with no build step, served by GitHub Pages from the `master` branch. The typeface is Public Sans, self-hosted under the SIL Open Font License (`fonts/OFL-PublicSans.txt`).
